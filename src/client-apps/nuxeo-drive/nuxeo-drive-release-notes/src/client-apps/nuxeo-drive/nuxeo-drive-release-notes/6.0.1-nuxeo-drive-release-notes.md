## Core 

### End of Support macOS 13 

Starting from Nuxeo Drive 6.0.1, macOS versions supported are version15 (64 bit) and higher. 

## Upgrade Behavior 

We discovered an issue when upgrading from old Nuxeo Drive version to latest one, on Windows 11. The problem has to do with upgrade from 5.4.0 to 6.0.0. Upgrade from 5.5.x+ to 6.0.0 is unaffected. The issue has been fixed in Nuxeo Drive 6.0.1.
