## What's new in NEV 2.1.3

### {{> anchor 'summary'}} Summary

This release brings the ability to authenticate to NEV from a third-party system without having to authenticate against Web UI.

## Noteworthy Changes

- Ability to redirect user against a 3rd party system for OAuth2 challenge.<br/>[[NEV-90](https://hyland-sync.atlassian.net/browse/NEV-90)]
- Defunct processes are cleaned up regularly to improve overall stability.<br/>[[NEV-91](https://hyland-sync.atlassian.net/browse/NEV-91)]
